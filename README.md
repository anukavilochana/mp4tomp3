# QR Code Generator

A lightweight, user-friendly, and free web application that allows you to generate unlimited custom QR codes for any link or text instantly. 

**[Live Demo](https://anukavilochana.github.io/qrcodegenerator/)**

## Features

* **Unlimited Generation:** Create as many QR codes as you need without any restrictions or hidden costs.
* **Custom Sizes:** Choose from multiple resolution options to fit your specific needs:
  * Small (150x150)
  * Medium (200x200)
  * Large (300x300)
  * Extra Large (400x400)
* **Bilingual Support:** Interface includes localized text support (English & Sinhala).
* **Easy Downloads:** Export your generated QR codes instantly as high-quality PNG images.

## How to Use

1. Enter your target URL or text into the input field.
2. Select your preferred QR code size from the dropdown menu.
3. Click the **Generate QR Code** button.
4. Click **Download PNG** to save the QR code to your device.
